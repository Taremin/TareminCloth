# Taremin Cloth

Blender 5.2 LTS 向けの **GPU XPBD（Extended Position-Based Dynamics）布シミュレータアドオン** です。  
コア計算エンジンを Rust（`wgpu` / WGSL コンピュートシェーダー）で実装し、PyO3 (ABI3) を介して Blender とシームレスに連携します。

---

## ✨ 主な機能

- **⚡ 超高速 GPU 並列 XPBD ソルバー**:
  - Welsh-Powell グラフ彩色アルゴリズムによる頂点競合フリーな完全 GPU 並列拘束投影。
  - 伸縮拘束（Distance Constraints）および二面角曲げ拘束（Dihedral Angle Bending Constraints）。
- **✋ インタラクティブ操作 (Grab / Drag)**:
  - 3D ビューポート上でシミュレーションを実行しながら、マウスで布の頂点を掴んでリアルタイムに引っ張る操作が可能。
- **📌 ピン留め (Pinning)**:
  - 頂点グループ（`Pin` または `Cloth_Pin`）による固定ピン対応。
- **🧵 型紙縫合 (Pattern Seaming / Sewing)**:
  - 面に属さない孤立エッジ（Loose Edges）を「縫合線」として自動認識し、自然長を徐々に短縮して服の形状に縫い合わせ。
- **🛡️ 剛体 & メッシュコライダー (SDF & Triangle Mesh Collision)**:
  - 球（Sphere）、カプセル（Capsule）、無限平面（Plane）の SDF プリミティブ衝突判定。
  - 人体モデルや Suzanne などの **任意のポリゴンメッシュ（Mesh Collider）** との完全 GPU 並列衝突判定および摩擦力（Friction）シミュレーション。
- **🦴 ボーン局所SDFコライダー (Bone SDF Collision)**:
  - スキニング素体メッシュから各ボーンのローカル符号付き距離場（SDF）とウェイト（Alpha）を 3D Brick Atlas テクスチャへ事前ベイク。wgpu コンピュートシェーダーによる超並列ベイクに対応し、高解像度でもわずか 0.1 秒前後で生成完了。
  - アニメーション再生時、ボーン変換行列（4x4）のみを GPU 転送することで、高密度素体でも毎フレームのメッシュ転送負荷ゼロで超高速・安定した衝突判定を実現。
  - **フルGPU動的SDF更新（DYNAMIC_GPUモード）**:
    - 素体メッシュの頂点スキニング（LBS）からボーン局所射影・SDF再ベイク・テクスチャ更新までをすべて GPU（VRAM）内部で完結。
    - CPU側の `to_mesh()` や PCIe 転送待機を一切行わず、激しい曲げ変形にもミリ単位で追従する動的衝突判定を実現（更新間隔の調整にも対応）。
    - **ボーン単位のDirty差分更新**: ポーズ変化が生じたボーンおよびその影響を受けるボーンのみを依存関係グラフから自動特定し、GPUコンピュートシェーダーでピンポイントに差分再ベイク。静止時やキャラクター全体の平行移動時は再計算を完全スキップ（0ms）し、アニメーション時でも最大4〜10倍の高速化（70+ FPS）を達成。将来のシェイプキー変形時の差分更新にも対応可能な設計となっています。
  - **関節部メッシュ補完（ハイブリッドモード）**:
    - 腰を曲げる等の激しい屈曲アニメーション時に発生する剛体ブロックの角ばり突出を解消するため、複数ボーンのブレンド関節領域（全体の約10〜15%）のみ部分メッシュコライダーを自動抽出・併用。
    - **使い分け指針**: 静止画や軽微なポーズでは従来のBONE_SDF単体（高速性重視）で十分であり、腰や背骨を大きく曲げるアニメーション再生時に本オプションを有効化することで、全ポリゴンメッシュに比べて極めて軽量な転送負荷のまま、完璧な曲面追従を実現します。
- **📦 単一メッシュ直方体SDFコライダー (Mesh SDF Collision)**:
  - アーマチュア不要で、マネキン・剛体・静止素体・Suzanne などの任意のオブジェクト全体を単一の直方体 SDF テクスチャとして GPU 並列ベイク。
  - 三角形メッシュコライダーに比べて裏返りや高速突き抜けが起きにくく、滑らかで安定した衣服の着せ付けが可能。
  - **VRAM 上限予算 & Auto Fit VRAM（自動解像度最適化）**:
    - メッシュのバウンディングボックスとボクセルサイズからテクスチャ解像度・VRAM 消費量をリアルタイム推定。
    - 指定した上限予算（デフォルト 256MB）を超過する場合、安全なボクセルサイズへ自動逆算・最適化することで、低スペック環境での VRAM 圧迫やドライバクラッシュを防止。
- **🏃 コライダー変形アニメーション (Collider Animation Driver)**:
  - インタラクティブモードやシミュレーション中に、コライダーの **ボーン（ポーズ）やシェイプキー** を自動アニメーション駆動。
  - 関節を曲げたときの引っ張り・たわみシワを自然に生成し、掴んで整えるスカルプト的ワークフローを実現。
  - 2ポーズスナップショット補間（0.0 ⇔ 1.0）および既存アクション再生に対応。
  - 一度だけ（Once）、繰り返し（Repeat）、往復（Ping-Pong）、サイクルフレーム数、および布の暴れを防ぐイージング（Smoothstep）制御を搭載。
- **👕 マルチレイヤー & 自己衝突 (Multi-Layer)**:
  - レイヤー優先度（Layer ID）と厚み（Thickness）に基づき、重ね着した布の突き抜けを防止。
- **🎨 3軸プリセットシステム & カスタム保存**:
  - **布素材 (Fabric)**: 絹（Silk）、木綿（Cotton）、麻（Linen）、デニム（Denim）、革（Leather）、ゴム（Rubber）
  - **シミュレーション品質 (Quality)**: Fast（リアルタイム編集・高FPS）、Balanced（標準）、Best（レンダリング用高精度）、Stiff（伸び防止・紐やタイト服）
  - **コライダー特性 (Collider)**: 肌（Skin）、布（Fabric）、滑面・金属（Smooth/Metal）、高摩擦ゴム（Rubber）
  - ユーザーが調整したお気に入りのパラメータを名前をつけて保存・読み込み・削除可能（JSONファイル形式）。
- **💠 十字分割 & 最適トポロジー後処理 (Cross Subdivision & Post-Processing)**:
  - 四角面（Quad）特有の対角線折り目バイアスを解消するため、シミュレーション時に中心点を追加して4つの三角形に十字分割（Poke Faces）。
  - シミュレーション完了時、シワの稜線に沿った「最適な三角面2つ」への再分割、平坦部の「四角面復元（Quad化）」、または「アダプティブ自動判定」で出力可能。
- **🎮 GPU バックエンド & デバイス動的選択 (Hardware & Backend Selection)**:
  - 3D ビューポートの N パネルおよびアドオン設定（Preferences）から、計算バックエンド（**Auto / DirectX 12 / Vulkan**）と GPU デバイス（**dGPU / iGPU / マルチGPU環境**）を自由に選択・即座に再初期化可能。
  - 現在アクティブな GPU 名とバックエンド種別をパネル上に常時ステータス表示。

## 📦 インストール / 導入手順

### 1. 配布用 zip からインストールする場合（推奨・一般ユーザー向け）

1. GitHub の [Releases](https://github.com/taremin/taremin_cloth/releases) ページから、お使いの環境に合った最新の zip ファイルをダウンロードします：
   - **Windows**: `taremin_cloth-vX.Y.Z-windows-x64.zip`
   - **Linux**: `taremin_cloth-vX.Y.Z-linux-x64.zip`
   - **macOS**: `taremin_cloth-vX.Y.Z-macos-universal.zip` (Apple Silicon / Intel 両対応)
2. Blender を起動し、**「編集 (Edit)」 > 「プリファレンス (Preferences)」 > 「アドオン (Add-ons)」** を開きます。
3. 右上の **「ディスクからインストール... (Install from Disk...)」** をクリックし、ダウンロードした zip ファイルを選択します。
4. リストに表示された **Taremin Cloth** のチェックボックスをオンにして有効化します。

### 2. ソースコードから開発 / ビルドする場合

Rust ツールチェーンがインストールされている環境で以下を実行します：

```powershell
# プロジェクトルートでビルド
cargo build --release

# 生成された DLL を .pyd として配置（Windowsの場合）
Copy-Item target\release\taremin_cloth_core.dll taremin_cloth_core.pyd
```

アドオンディレクトリ（例: Windows の場合は `%APPDATA%\Blender Foundation\Blender\5.2\scripts\addons\`）に本フォルダを配置、またはシンボリックリンクを作成して有効化します：

```powershell
# 例: アドオンディレクトリへシンボリックリンクを作成
New-Item -ItemType SymbolicLink -Path "$env:APPDATA\Blender Foundation\Blender\5.2\scripts\addons\taremin_cloth" -Target (Get-Location).Path
```

#### 配布用 zip をローカルで作成する場合:
```powershell
# ローカルのバイナリを含めた配布用 zip を dist/ に生成
python tools/package_addon.py
```

## 🚀 基本的な使い方

### 1. 布・コライダー一覧からの選択と管理 (Cloth & Collider Objects)

N パネルの最上部にある **「Cloth & Collider Objects」** パネルで、シーン内の全布・コライダーオブジェクトを一元管理・迅速に選択・制御できます：
- **ワンクリック選択**: リスト内のオブジェクト名ボタンをクリックすると、シーン内の該当オブジェクトが即座にアクティブ選択され、下の設定パネル（GPU Cloth / GPU Collider）が連動して切り替わります。選択中のオブジェクトはボタンがハイライト（凹み）表示されます。
- **メタ情報の把握**: 各オブジェクトの横に、布のレイヤー番号（`L0`, `L1` 等）やコライダーの形状種別（`Sphere`, `Capsule`, `Plane`, `Mesh`）がバッジ表示されます。
- **シミュレーション一時無効化（ミュート/バイパス）**:
  - 各行の物理アイコン（`PHYSICS`）をクリックして OFF にすると、**メッシュの見た目を維持したまま**、タイムライン再生やインタラクティブモードでの計算・衝突判定から一時的に除外されます。
  - 特定の布だけを動かしたい場合や、重いコライダーを一時的にスキップしたい場合に便利です。
- **ビューポート表示/非表示の切り替え**: リスト右端の目のアイコンで、各オブジェクトのビューポート可視性をワンクリックで切り替えられます。
- **クイック一括操作 (Batch Actions)**:
  - **`All ON`**: シーン内の全布・コライダーのシミュレーションを有効化。
  - **`All OFF`**: 全てのシミュレーションを一時停止（ミュート）。
  - **`Solo`**: 選択中のオブジェクトのみ有効化し、他の全オブジェクトを一時停止（単一部位のテストに最適）。
- **シミュレーション構成プリセット (Simulation Set / Config Presets)**:
  - 「上半身のみ」「インナーのみ」「軽量テスト用」など、シーン内の布・コライダーの有効/無効状態の組み合わせに名前をつけて **「＋」ボタン** で保存できます。
  - ドロップダウンから選択するだけで、いつでもその構成を一括復元できます（.blend ファイル内に永続保存されます）。

### 2. 布シミュレーションの実行

1. 3D ビューポートで布にしたいメッシュオブジェクト（平面やグリッドなど）を選択します。
2. 3D ビューポートのサイドバー（**Nキー**）を開き、**「Taremin Cloth」** タブを選択します。
3. **「Enable Cloth」** ボタンをクリックします。
4. タイムラインを再生（**スペースキー**）すると、重力に従って布がリアルタイムに変形・落下します。

### 3. ピン留め (固定頂点の設定)

1. オブジェクトの頂点グループに `Pin`（または `Cloth_Pin`）という名前のグループを作成します。
2. 固定したい頂点を選択し、ウェイト `1.0` を割り当てます。
3. シミュレーションを再生すると、ピン留めされた頂点が空間に固定されます。

### 4. インタラクティブ操作 (Grab / Drag モード)

1. 布オブジェクトを選択した状態で、N パネルの **「Interactive Mode (Grab/Drag)」** をクリックします。
2. 3D ビューポート上で布の任意の頂点を **左クリック＋ドラッグ** すると、リアルタイムに布を引っ張ることができます。
3. **右クリック** または **ESC キー** でインタラクティブモードを終了します。

### 5. 型紙の縫合 (Sewing)

1. 2枚の布メッシュ（前身頃・後身頃など）を同一オブジェクト内に用意します。
2. 縫い合わせたい境界頂点同士を **Fキー** で結び、エッジ（面に属さない線）を作成します。
3. N パネルの **「Sewing (Pattern Seaming)」** ボックスで **「Enable Sewing」** にチェックを入れます。
4. **「Shrink Speed」**（収縮速度）を調整してタイムラインを再生すると、エッジが引き合わされて縫合されます。

### 6. コライダー設定 (SDF プリミティブ & カスタムメッシュ)

1. 障害物としたいオブジェクト（人体モデル、Suzanne、球、床など）を選択します。
2. N パネルの **「GPU Collider」** > **「Enable Collider」** にチェックを入れます。
3. **Collider Shape** を選択します：
   - **`Mesh`**: 選択オブジェクトのポリゴンメッシュ全体をコライダーとして使用します（人体モデル等に最適）。
     - **`Thickness`**: 表面オフセット厚みを設定可能。
     - **`Single Sided`**（片面衝突判定、デフォルト: ON）: メッシュの表面（法線方向）からの侵入のみを遮断し、裏側からの脱出を妨げません。アバターの体内に布がめり込んでしまった場合でも、服が引っ張られた際に自然に体外へ抜け出せるようになります。薄い壁のように両面から接触させたい場合はチェックを外します。
   - **`Sphere` / `Capsule` / `Plane`**: 解析的 SDF プリミティブによる超高速衝突判定。
4. **Friction**（摩擦係数）および **Restitution**（反発係数）を調整してシミュレーションを実行すると、布が表面に接触して自然に滑り落ちる・留まる挙動になります。

### 7. 重ね着 (Multi-Layer) & 自己衝突・貫通解消 (Self Collision & Untangling)

1. **重ね着 (Multi-Layer)**:
   - 内側の服（インナー）の **Layer ID** を `0`、外側の服（アウター）の **Layer ID** を `1` に設定します。
   - **Thickness**（厚み）を設定してシミュレーションを実行すると、外側の服が内側の服を押し込まずに外側へ追従します。
2. **自己衝突 (Self Collision)**:
   - N パネルの **「Layer & Collision」** で **「Self Collision」** にチェックを入れます（GPU空間ハッシュによる完全並列高速判定）。
3. **貫通解消・高度オプション (Untangling & Soft Relief)**:
   - **`Relief Factor`（緩和係数）**: 貫通や強い接触が起きた際の反発緩和率（デフォルト: 0.2）。急激に弾き飛ばさず数フレームかけて滑らかに外へ押し出すことで、布の破裂（Blow-up）や激しい振動を防止します。
   - **`Max Step Ratio`（最大変位割合）**: 周囲のエッジ長に対する1サブステップあたりの最大補正変位割合（デフォルト: 0.2）。小物から大布までスケールやメッシュ解像度に関係なく破綻を防止します。
   - **`Search Limit`（最大探索反復回数）**: GPU空間ハッシュの1セルあたり探索上限。`128 (Fast)`, `256 (Balanced)`, `512 (High Quality)`, `1024 (Ultra)`, `4096 (No Limit)` から選択可能。複雑な折り畳みや高密度布でのすり抜けを防止します。
   - **`Auto Fit`（厚み自動設定ボタン）**: メッシュの平均エッジ長を測定し、貫通やすり抜けを防ぐ推奨の厚み（`Thickness`）をワンクリックで自動設定します。
   - **`隣接頂点の自動除外`**: メッシュのエッジや縫合線で直接繋がっている隣接頂点を自己衝突から自動除外し、自縄自縛や意図しない縮み、カタパルト爆発を根本的に防止します（常時自動適用）。
   - **`多層布の法線貫通復元 (Normal Untangling)`**: GPU頂点法線を用いて裏抜けした外側レイヤーを表側へ押し戻し、重ね着の巻き込みや突き抜けからの自律的な脱出を保証します（常時自動適用）。

### 8. 適応型サブステップ (Adaptive Steps / 高速化と破綻防止)

1. N パネルの **「Simulation Settings」** ボックスで **「Adaptive Steps」** にチェックを入れます。
2. 布の移動量やコライダーの急激な動きに応じてサブステップ数を **Min Steps** 〜 **Max Steps** の間で動的に自動調整します：
   - **CFL条件連動**: メッシュの最小エッジ長と厚みから特性長を割り出し、エッジ長に対して移動量が大きくなると自動でステップ数を増やして反転や突き抜けを防止します。激突などの突発的な高速移動時には **Max Steps**（デフォルト: 64）まで自動伸長し、トンネリング（すり抜け）を完全に遮断します。
   - **コライダー移動量追跡**: 手足や武器が急激に動いて布に突っ込んできた瞬間に先んじてステップ数を引き上げ、貫通を防ぎます。
   - **平滑化（ジッター防止）**: ステップ数を下げるときは数フレームかけて緩やかに減少させ、剛性感の揺らぎによる布のピクつきを防止します。
   - **静止・整定時のFPS向上**: 布が落ち着いているときは最小ステップ数（**Min Steps**、デフォルト: 4）に抑えられ、シーン全体のフレームレートが大幅に向上します。

### 9. 伸縮グループ (Elastic Bands / ゴム紐・ギャザー機能)

ウエストのゴム絞り、袖口・裾の引き締め、首元のギャザーなどを、シミュレーション中やインタラクティブモード中にリアルタイムに調整できます。

1. **Editモードで辺を選択**:
   - Blenderの標準ツール（**Alt + 左クリック** での辺ループ選択、**Ctrl + Alt + 左クリック** での辺リング選択など）で、絞りたい辺を選択します。
2. **グループの作成**:
   - N パネルの **「Elastic Bands / Edge Scaling」** ボックスで **「＋」** ボタンをクリックすると、選択中の辺が新規グループとして登録されます。
3. **リアルタイム倍率調整**:
   - シミュレーション再生中やインタラクティブモード中に **「Scale」** スライダーを操作します：
     - **`1.0`**: 等倍（変形なし）
     - **`0.5`**: 50%に収縮（ギュッと絞る）
     - **`1.5`**: 150%に伸長（広げる・たるませる）
4. **テンションの視覚化（カラーオーバーレイ）**:
   - 3Dビューポート上で、縮小中の辺は **シアン〜ブルー**、伸長中の辺は **オレンジ〜レッド** で発色します。
   - 布が引き絞られて目標の長さに収束するにつれて、透明度がフェードアウトして自然に消え、安定したことが一目で分かります。

### 10. エッジ詳細接触判定 (Edge Collision / 多面体突き抜け防止)

粗いメッシュコライダー（ICO球やローポリモデルなど）の尖った角やエッジが、布のポリゴン中央を突き抜けて飛び出す現象を防止します。

1. 布オブジェクトの N パネル > **「Layer & Collision」** ボックスを開きます。
2. **「Edge Collision」** にチェックを入れます。
3. 布の各エッジ中点およびコライダー頂点との最近傍点を仮想接触点としてGPU並列判定し、布の面の中央の沈み込み（弦のたるみ）や多面体の角の貫通を強力に防止します。
4. **「Margin Scale」** スライダー（デフォルト: `1.0`、推奨: `1.1`〜`1.3`）:
   - 全体の厚み（`Thickness`）は薄いまま保って自然な密着感を維持しつつ、突き抜けが起きやすいエッジや面の中央部分だけに安全マージン倍率を掛けます。
   - `1.2` 程度に引き上げることで、服のフィット感を損なわずに角抜けやポリゴン交差を完全にシャットアウトできます。
5. **「Margin Offset」** スライダー（デフォルト: `0.0m`、単位: 長さ[m/cm/mm]）:
   - エッジ接触時の目標距離に**固定値（絶対距離）を加算**します。
   - 薄いシルク生地など `Thickness` が非常に小さく、倍率（Scale）だけではマージンが不足する場合でも、`+2mm`〜`+5mm` などの安全クリアランスを確実に確保できます。

### 11. コライダー変形アニメーション (Collider Animation Driver)

肘や膝などの関節を曲げたポーズ変化や、体型変化（シェイプキー）によって自然なシワを発生させ、リアルタイムに整えることができます。

1. **コライダーのアニメーションを有効化**:
   - コライダーオブジェクトを選択し、N パネルの **「GPU Collider」** > **「Collider Animation」** > **「Enable Animation」** にチェックを入れます。
2. **アニメーション方式の選択**:
   - **`Pose Blend` (推奨)**:
     - 開始姿勢（0.0）と目標姿勢（1.0、例: 肘を曲げた状態）の2ポーズ間でブレンドします。
     - **「Rec Start (0.0)」**: 現在のアーマチュアのポーズを開始姿勢として記録。
     - **「Rec Target (1.0)」**: 曲げた状態のポーズを目標姿勢として記録。
     - **「0.0」 / 「1.0」 / 「Rest」**: 保存したポーズやレスト姿勢をいつでも即座にプレビュー復元。
   - **`Shape Key`**:
     - メッシュのシェイプキー名、開始値（Start）、終了値（End）を指定して変形。
   - **`Action`**:
     - 既存のアニメーションアクションを指定し、指定フレーム範囲（Start F 〜 End F）を評価。
3. **再生サイクルの設定**:
   - **Mode**:
     - **`Once`**: 0.0 から 1.0 までゆっくり変形して停止（シワを作って固定し、Grab/Drag で整えたい場合に最適）。
     - **`Repeat`**: 1.0 に達したら先頭に戻って繰り返し再生。
     - **`Ping-Pong`**: 順再生と逆再生を往復（屈伸・歩行サイクルの検証に最適）。
   - **Cycle Frames**: 1サイクルにかけるフレーム数（例: 60フレーム = 1秒）。
   - **Easing**: **`Smooth (Ease In-Out)`** を選ぶと、始点と終点で滑らかに加減速し、急な動きによる布の暴れやめり込みを防止します。
   - **Progress スライダー**: シミュレーション開始前でもスライダー操作でリアルタイムにポーズ変化をスクラブ確認できます。
4. **インタラクティブモードでシワを調整**:
   - インタラクティブモードを開始すると、設定した速度でコライダーが滑らかに変形し、布に自然なシワが寄ります。停止後にマウスでシワの山谷を掴んで整えたり、ピン留めして理想的な形状に仕上げることができます。

### 12. プリセットの活用 (素材・品質・コライダーのワンクリック適用 & 自作保存)

1. **プリセットの適用**:
   - 各セクションのドロップダウン（**Material Preset**, **Quality Preset**, **Collider Preset**）をクリックし、目的のプリセット（例: `Silk (絹)`, `Fast (Realtime)`, `Skin (Human)` など）を選択すると、即座に最適なパラメータが反映されます。
2. **カスタムプリセットの保存**:
   - スライダーで微調整したお気に入りの設定値を、プリセットメニュー横の **「＋」ボタン** から名前をつけて保存できます。
   - 保存されたカスタムプリセットは次回以降メニューの「Custom Presets」一覧に自動表示されます。
3. **カスタムプリセットの削除**:
   - 不要になったカスタムプリセットは **「－」ボタン** から削除できます（ビルトインの標準プリセットは保護されます）。

### 13. メッシュトポロジー & 分割 (Topology & Triangulation)

四角面メッシュで布シミュレーションを行う際、四角面の対角線方向の折り目が目立ったり、特定の対角線だけに折れ曲がりが偏る（対角線バイアス）現象を解消します。

1. **動的対角線分割 (`Dynamic Diagonal`)【推奨・最軽量】**:
   - **特徴**: シミュレーション中の頂点数・面数は**一切増加しません**。そのため通常のローポリゴンQuadと同じ超高速FPSと低負荷を維持できます。
   - **動作**: シミュレーション中、各四角面の両対角線に対称なせん断拘束（Shear）を均等に付与して等方的な布としてシミュレーションし、シミュレーション停止時に**対角線の歪み（伸び縮み率: Strain）を比較して折り目の稜線となる最適な対角線で四角面を2分割**します。
   - **オプション**:
     - `Preserve Flat Quads`: 平坦な面は2分割せずQuadのまま残すことでメッシュを軽量化します。
     - `Auto Triangulate on Stop`: シミュレーション停止時に自動で最適分割を実行します。
     - 手動実行: **「Split by Strain」** ボタンでいつでも分割、**「Restore Quad」** ボタンで元の四角面に復元できます。

2. **十字分割 (`Cross Subdivision / Poke`)【高精度】**:
   - 四角面の中央に中心頂点を追加して4つの三角形に分割（Poke Faces）します。
   - ドーム状やテント状の強い突起・湾曲部を表現できますが、頂点数が約2倍、面数が4倍になるため中〜高負荷となります。
   - **後処理モード**:
     - `Optimal 2 Triangles`: シミュレーション後の幾何形状から最適対角線を選び2分割（中心頂点を削除して元の頂点数に復元）。
     - `Restore Quad`: 元の四角面メッシュに完全復元。
     - `Adaptive`: 平坦部はQuad、シワ部は最適2三角面、強いドーム突起部は十字分割（4三角面）を維持。
     - `Keep Cross`: 十字分割のまま保持。

### 14. GPU バックエンド & デバイス選択 (GPU & Hardware Settings)

お使いのグラフィックボードやBlenderのバージョン、マルチGPU環境に合わせて、最適な計算バックエンドとGPUデバイスを選択できます。

1. N パネル最下部、または `編集 > プリファレンス > アドオン > Taremin Cloth` の **「GPU & Diagnostics」** ボックスを開きます。
2. **Backend**:
   - `Auto (推奨)`: OSに最適なAPI（WindowsはDirectX 12優先、Linux/macOSはVulkan/Metal優先）
   - `DirectX 12`: Windows標準API（Blender本体描画との競合が少なく最も安定）
   - `Vulkan`: クロスプラットフォーム対応の高速API
3. **Device**:
   - `Auto (High Performance)`: 高性能GPU（dGPU）を自動選択
   - 検出された物理GPU一覧（例: `NVIDIA GeForce RTX 4090 (DirectX 12)`, `AMD Radeon RX 9070 XT (Vulkan)` 等）から明示的に選択
4. **「Apply GPU Settings」** ボタンをクリックすると、GPUコンテキストが安全に再初期化され、`Active: [GPU名] ([Backend])` に稼働状態が表示されます。

### 14. シミュレーション状態のデバッグ記録と完全再現 (Debug Recorder & Replayer)

シミュレーション中の物理挙動の解析や異常値（NaN、速度爆発、貫通など）の調査用として、各フレームの状態（位置・速度・動的ピン目標座標・コライダー情報・物理パラメータ一式）をRust側でメモリ記録し、終了時にgzip圧縮JSON Lines（`.jsonl.gz`）として出力できます。

1. **有効化**:
   - `編集 > プリファレンス > アドオン > Taremin Cloth` を開き、**Console Log Level** を **`DEBUG`** に設定します。
   - **Simulation Frame Debug Recorder** の **「Enable Debug Recording」** にチェックを入れます。
2. **出力設定**:
   - **Output Folder**: 保存先ディレクトリ（空欄時はアドオン内の `frame_logs` フォルダを使用）。
   - **Template**: ファイル名テンプレート。デフォルト: `cloth_debug_{datetime}_{object}.{ext}`（拡張子 `{ext}` は自動的に `jsonl.gz` となります）。
   - **Max Frames**: メモリ保護用の最大記録フレーム数（デフォルト: 3600フレーム = 60FPSで約1分間）。
3. **実行と出力**:
   - インタラクティブモードを実行し、ESC または右クリックで終了すると、自動的に指定フォルダへ `.jsonl.gz` が保存され、コンソールおよび情報ヘッダーに保存パスとフレーム数が通知されます。
4. **Blender非依存の解析・再現・可視化CLI (`log_tools`)**:
   Blenderを一切起動することなく、ログの異常検知、貫通レンダリング、最小テストケース生成が可能です（詳細は [AGENTS.md](AGENTS.md) 参照）。
   ```bash
   # ログ全体の異常値を走査
   python -m taremin_cloth.log_tools inspect cloth_debug.jsonl.gz

   # 問題フレームの貫通・裏返り確認（表面:白、裏面:赤の0.1秒超軽量レンダリング）
   python -m taremin_cloth.log_tools render cloth_debug.jsonl.gz --frame 71 --output scratch/f71.png

   # 問題直前のフレームから始まる自己完結型 unittest スクリプトを自動生成
   python -m taremin_cloth.log_tools make-test cloth_debug.jsonl.gz --frame 71 --lookback 3 --output tests/test_issue_f71.py
   ```
